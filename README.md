# Tarea 2 IIC3675 Aprendizaje Reforzado

## Setup
Para empezar, descargamos las dependencias necesarias para poder correr los experimentos.

```
pip install -r requirements.txt
```

## MDP
Para correr los experimentos, se debe ingresar a la carpeta MDPs, y correr el script run_experimentos.py. Luego, se debe elegir por medio de la consola el problema, el algoritmo, y la política a probar.

```
cd MDPs/
python3 run_experiments.py
```

## Monte Carlo

Para correr los experimentos de Monte Carlo, se debe ingresar a la carpeta MonteCarlo, y correr el script run_experiments. Luego se debe elegir el problema para el cual se quiere probar el algoritmo.

```
cd MonteCarlo/
python3 run_experiments.py
```
